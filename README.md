# PythonBasics

## Educational mini-project in this repository

- **Path:** `nlp_basics`
- **Focus:** foundational tokenization helpers (ngrams, frequency, sentence split, term checks).
- **Run:** `cd nlp_basics && python -c "from token_lab import tokens; print(tokens('Search ranking demo'))"`
- **Test:** `cd nlp_basics && python -m unittest test_token_lab.py`
